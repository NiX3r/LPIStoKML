Kde stáhnout ZIP soubor s SHP daty?
  • Jdi na eagri.cz → LPIS data
  • Nastav: Entita = DPB, Typ = SHP, Území = Okres
  • Klikni Vygenerovat seznam souborů a stáhni první řádek (celý okres)
  • Pokud se nenajdou žádné bloky, stáhni i sousední okresy a vyber všechny ZIP soubory najednou
  • Data se aktualizují týdně — stahuj vždy nejnovější export
