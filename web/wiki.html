LPIS → KML

Průvodce exportem půdních bloků ze státního registru LPIS do aplikace DJI FlightHub 2 pro plánování dronových misí — záchrana srnčat před sekačkou.

Co to je?

Tento nástroj převádí data o půdních blocích ze státního registru LPIS (Land Parcel Identification System) do formátu KML, který lze importovat do aplikace DJI FlightHub 2 a použít jako podklad pro plánování dronových misí.

Hlavním účelem je pomoci zemědělcům a záchranářům přesně vymezit plochy před sečením a systematicky je prohledat dronem — aby srnčata a jiná zvěř mohla být včas přenesena do bezpečí.

Co je LPIS? LPIS je veřejný registr Ministerstva zemědělství ČR, který eviduje půdní bloky (DPB) — základní jednotky zemědělské půdy přiřazené konkrétním hospodářům. Data jsou volně dostupná ke stažení.

Jak to funguje?

Aplikace přijme ZIP soubor stažený z portálu LPIS (obsahující SHP soubory), filtruje záznamy podle zadaného ID_UZ hospodáře, přeprojektuje souřadnice z S-JTSK do WGS-84 a vygeneruje soubor KML připravený pro DJI FlightHub 2.

Data zůstávají u tebe Vše se zpracuje přímo v prohlížeči. ZIP soubory se nikam nenahrávají a aplikace funguje i jako obyčejná statická stránka (např. na GitHub Pages).
  1. Zjistíš ID_UZ zemědělského subjektu z veřejného LPIS registru.
  2. Stáhneš SHP data pro příslušný okres z portálu eagri.cz.
  3. Nahraješ ZIP soubor do této aplikace a zadáš ID_UZ.
  4. Stáhneš vygenerovaný KML soubor.
  5. Importuješ KML do DJI FlightHub 2 přes Map Annotations → Import.

Krok 1: Zjisti ID_UZ zemědělského subjektu

Každý zemědělec má v systému LPIS přiděleno identifikační číslo ID_UZ (také označované jako ID LPIS). Toto číslo je nutné pro filtrování půdních bloků daného hospodáře z dat celého okresu.

Jak ID_UZ najít

  1. Jdi na mze.gov.cz → LPIS veřejný registr.
  2. V záložce napravo zadej název Obce, kde zemědělec hospodaří, a klikni Vyhledat.
  3. V seznamu výsledků klikni na název zemědělského subjektu.
  4. Zaznamenej si číslo ID LPIS (například 89677) — to je tvé ID_UZ.
Tip Zemědělec může hospodařit na blocích v různých obcích nebo okresech. ID_UZ je vždy jedno a stejné bez ohledu na polohu pozemků.

Krok 2: Stáhni SHP data z LPIS

Data o půdních blocích (DPB) jsou dostupná na portálu eagri.cz jako ZIP soubory obsahující SHP (Shapefile) — standardní GIS formát pro vektorová data.

Postup stahování

  1. Jdi na eagri.cz → LPIS data.
  2. Filtruj podle okresu, kde zemědělec hospodaří (nebo kraje pro větší pokrytí).
  3. Nastav: Entita = DPB, Typ = SHP.
  4. Klikni Vygenerovat seznam souborů.
  5. Stáhni první řádek, kde Území = Okres — to je souhrnný soubor pro celý okres.
Zemědělec hospodaří ve více okresech? Stáhni ZIP soubory pro všechny příslušné okresy a v aplikaci je vyber (nebo přetáhni) všechny najednou — bloky ze všech okresů se spojí do jednoho KML.
Aktuálnost dat Data LPIS se aktualizují týdně. Vždy stahuj nejnovější export, zejména na začátku sezóny nebo po změnách v užívání pozemků.

Krok 3: Převod na KML

Po stažení ZIP souboru přejdi na hlavní stránku aplikace a postupuj takto:

  1. Přetáhni ZIP soubor (nebo více souborů) do oblasti nahrávání, nebo je vyber kliknutím.
  2. Zadej ID_UZ zemědělského subjektu.
  3. Volitelně vyplň název výstupního souboru (bez přípony). Pokud necháš prázdné, použije se lpis_export.
  4. Chceš exportovat jen jeden konkrétní blok? Vyplň jeho číslo (např. 4003/2) do pole „Číslo půdního bloku".
  5. Klikni Převést a stáhnout KML. Soubor se automaticky stáhne, zobrazí se počet nalezených bloků a náhled jejich tvarů.
Název souboru s lomítkem Číslo bloku jako 6903/9 nelze použít jako název souboru. Použij místo toho podtržítko: 6903_9.

Krok 4: Import do DJI FlightHub 2

  1. Otevři DJI FlightHub 2 a vyber projekt.
  2. V levém panelu klikni na ikonu Map Annotations.
  3. Klikni na ikonu Import (šipka dolů).
  4. Vyber stažený KML soubor.
  5. Všechna pole se zobrazí na mapě s čísly půdních bloků jako názvy.
Drobný posun polygonů je normální LPIS data a satelitní snímky v DJI nejsou dokonale zarovnány, ale přesnost je pro dronové mise dostačující.

Tipy a řešení problémů

Nalezeno 0 bloků

Zemědělec pravděpodobně hospodaří v jiném okrese. Stáhni SHP data i pro sousední okresy a vyber v aplikaci všechny ZIP soubory najednou.

Chybové hlášení „Sloupec ID_UZ nenalezen"

ZIP soubor pravděpodobně neobsahuje DPB data — ověř, že při stahování z eagri.cz bylo nastaveno Entita = DPB. Jiné entity (např. BPEJ, LPIS_FB) mají odlišnou strukturu sloupců.

Velký ZIP soubor (celý kraj)

Soubory se načítají do paměti prohlížeče. Data za okres zvládne každý počítač, u souborů za celý kraj (stovky MB) může být zpracování pomalé — v takovém případě stáhni jen příslušné okresy.

Neplatný ZIP soubor

Ujisti se, že ZIP soubor není poškozený a byl stažen celý. Zkus ho před nahráním otevřít v průzkumníku souborů.

Instalace a spuštění (lokálně)

Aplikace je čistě statická (HTML + JavaScript) — nepotřebuje žádný backend. Stačí složku web/ obsloužit libovolným webovým serverem, například: 

python -m http.server 5000 --directory web

nebo přes přiložený Flask server:

pip install -r requirements.txt
python app.py

Aplikace poběží na http://localhost:5000.
